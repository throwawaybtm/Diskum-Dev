# Konsep Utama: Awan Diskum
Sebuah portal kerja berbasis web yang mengubah proses pengarsipan manual menjadi ekosistem digital terpusat. Sistem ini secara otomatis menghubungkan pengisian data dengan buku register dan lemari penyimpanan file tanpa intervensi manual.

## 1. Tiga Pilar Sistem (Infrastruktur)
* **Pusat Kendali (Web Portal):** Tampilan visual yang digunakan pengguna sehari-hari untuk bekerja—memasukkan data baru, menelusuri arsip, dan melihat laporan.
* **Buku Besar (Database Sheets):** Berfungsi sebagai buku register otomatis yang mencatat rincian informasi setiap surat secara berurutan dan terstruktur.
* **Lemari Arsip (Brankas Drive):** Berfungsi sebagai rak folder digital tempat menyimpan file fisik (scan PDF) surat, yang terorganisir sesuai kategorinya.

## 2. Alur Kerja Pengguna (User Journey)
* **Pencatatan Satu Pintu:** Staf membuka portal web, mengetik ringkasan surat (nomor, tanggal, perihal), dan melampirkan file PDF surat tersebut.
* **Kerja di Balik Layar:** Begitu tombol "Simpan" ditekan, sistem memecah tugas secara mandiri. Informasi teks dicatat ke Buku Besar, sementara file PDF dikirim langsung ke folder kategori yang tepat di Lemari Arsip.
* **Akses & Temu Kembali:** Saat staf atau pimpinan membutuhkan surat lama, mereka cukup mengetik kata kunci di kolom pencarian portal, lalu sistem akan langsung memunculkan data beserta tombol untuk melihat file PDF-nya.

## 3. Fitur Utama
* **Penyortiran Otomatis:** Sistem yang mengenali jenis dokumen yang diunggah dan langsung merapikannya ke dalam laci digital yang tepat (misal: masuk ke folder "Surat Undangan").
* **Dasbor Kuantitatif:** Layar depan portal langsung menyajikan angka ringkasan statistik (volume surat masuk vs keluar) sebagai gambaran produktivitas.
* **Pencarian Instan:** Mesin pencari internal yang menemukan dokumen spesifik dalam hitungan detik, menghilangkan kebutuhan membolak-balik tumpukan kertas.
* **Ekspor Laporan:** Fitur sekali klik untuk menarik seluruh data persuratan dalam rentang waktu tertentu menjadi laporan siap cetak untuk kebutuhan audit atau rapat.
